# Личный VPN для Китая

Свой сервер, который проходит Великий китайский файрвол (GFW). Ставится одной командой на зарубежный VPS.

| Протокол | Транспорт | Роль | Почему проходит GFW |
|---|---|---|---|
| **VLESS + REALITY + Vision** (Xray) | TCP 443 | Основной | Для цензора выглядит как обычный HTTPS к `www.microsoft.com`: настоящий TLS 1.3, настоящий сертификат сайта. На активное зондирование сервер отвечает как сам Microsoft. |
| **Hysteria2 + Salamander** | UDP 443 (+ port hopping 20000–50000) | Резервный и быстрый | QUIC с обфускацией, не похож ни на один известный протокол. Держит скорость на плохих каналах, где TCP тормозит (вечером в Китае это очень заметно). |

Дополнительно:
- **BBR** и тюнинг TCP-буферов для скорости
- Сервер **блокирует китайские IP/домены**, поэтому через него нельзя «прозвонить» сервер изнутри Китая
- Профиль для клиента с **раздельной маршрутизацией**: Baidu, WeChat, Taobao, Alipay и банки идут напрямую (быстро и без капчи), всё остальное через VPN
- **Автопереключение**: если REALITY заблокировали, клиент сам переходит на Hysteria2
- Команда `vpn` для управления: ссылки, QR-коды, статус, обновление, смена ключей

## Шаг 1. Купить VPS (вне Китая)

Нужен самый дешёвый Linux-сервер: **1 vCPU, 512 МБ–1 ГБ RAM, Ubuntu 22.04/24.04 или Debian 12**.

**Что важно для Китая:**
- **Локация:** Япония (Токио/Осака), Сингапур, Корея или западное побережье США (Лос-Анджелес). Гонконг близко, но часто дорогой и с перегруженными каналами.
- **Маршрут:** лучше всего тарифы с **CN2 GIA**, **CMI** или **9929**. На обычных дешёвых серверах вечером (20:00–24:00 по Пекину) может сильно падать скорость. Если сервер с маршрутом CN2 GIA тебе не по карману, бери обычный: Hysteria2 частично сглаживает плохой канал.
- **Примеры:** BandwagonHost (тарифы CN2 GIA-E), DMIT (Premium/CN2 GIA), Vultr / DigitalOcean / Linode (Токио, Сингапур). Последние дешевле и удобнее, но маршрут хуже.
- **Оплата:** карта, PayPal или крипта. Многие принимают Alipay.

> Чтобы пережить блокировку IP, выбирай провайдера, который позволяет **сменить IP** (у Vultr/DO это просто пересоздание сервера, у BandwagonHost есть платная смена IP).

После покупки у тебя будут **IP-адрес** и **пароль root** (или SSH-ключ).

## Шаг 2. Установить VPN на сервер

С ноутбука подключись к серверу (SSH к зарубежным серверам из Китая обычно работает):

```bash
ssh root@IP_СЕРВЕРА
```

Залей на сервер папку `server/` из этого репозитория. Вариант А — если репозиторий публичный:

```bash
apt update && apt install -y git
git clone -b claude/personal-vpn-setup-mbzm2f https://github.com/akbar6726/Vpn-.git
cd Vpn-/server
bash install.sh
```

Вариант Б — если репозиторий приватный, скопируй файлы с ноутбука (на ноутбуке, из папки репозитория):

```bash
scp server/install.sh server/vpn root@IP_СЕРВЕРА:/root/
ssh root@IP_СЕРВЕРА "bash /root/install.sh"
```

Установка занимает 1–2 минуты. В конце скрипт покажет **ссылки и QR-коды**. Их можно в любой момент вывести снова командой:

```bash
vpn show
```

### Необязательные настройки

```bash
# Другой сайт для маскировки REALITY (должен открываться из Китая и поддерживать TLS 1.3 + HTTP/2)
REALITY_SNI=www.apple.com bash install.sh

# Без port hopping
NO_PORT_HOPPING=1 bash install.sh
```

Хорошие кандидаты для `REALITY_SNI`: сайты, которые не заблокированы в Китае, лучше с серверами рядом с твоим VPS. Например: `www.microsoft.com`, `www.apple.com`, `itunes.apple.com`, `www.amazon.com`, `www.yahoo.co.jp` (для японского VPS). Скрипт сам проверяет, подходит ли сайт.

## Шаг 3. Клиент на ноутбуке

> ⚠️ Скачай клиент **заранее** или через любой временный VPN: GitHub из Китая работает с перебоями.

### Вариант 1 (рекомендую): Clash Verge Rev — Windows / macOS / Linux

Самый удобный вариант для Китая: умные правила, автопереключение между протоколами, режим TUN для всех программ.

1. Скачай: https://github.com/clash-verge-rev/clash-verge-rev/releases
   (Windows: `..._x64-setup.exe`, Mac M1–M4: `..._aarch64.dmg`, Mac Intel: `..._x64.dmg`)
2. Забери профиль с сервера (на ноутбуке):
   ```bash
   scp root@IP_СЕРВЕРА:/root/vpn-client/clash-mihomo.yaml .
   ```
3. Clash Verge → **Профили** → **Импорт** (или перетащи файл) → выбери `clash-mihomo.yaml` → кликни по нему, чтобы активировать.
4. **Настройки** → включи **Системный прокси**: заработают браузер и большинство программ.
5. Для программ, которые игнорируют системный прокси (игры, Telegram Desktop в некоторых режимах, терминал, Discord, Docker), включи **TUN-режим** (виртуальная сетевая карта). Clash предложит установить службу, соглашайся.
6. На вкладке **Прокси** группа `PROXY` → `AUTO` (сам выбирает рабочий протокол). Можно вручную выбрать `REALITY` или `HYSTERIA2`.

### Вариант 2: Hiddify — Windows / macOS / Linux / Android / iOS

Проще для новичка, умеет импорт по ссылке.

1. Скачай: https://github.com/hiddify/hiddify-app/releases
2. Скопируй ссылки из `vpn show` (или файла `/root/vpn-client/links.txt`) → **Новый профиль** → **Добавить из буфера обмена**.
3. **Настройки → Регион: China (cn)**: китайские сайты пойдут напрямую.
4. Нажми большую кнопку подключения. Режим **VPN** охватывает все программы, режим **Системный прокси** только браузер и т.п.

### Вариант 3: v2rayN — Windows

1. https://github.com/2dust/v2rayN/releases (бери `v2rayN-windows-64-SelfContained.zip`)
2. Скопируй ссылку → **Серверы → Импорт из буфера обмена** (Ctrl+V).
3. Внизу: **Системный прокси → Автоматически**, **Маршрутизация → Обход материкового Китая** (`绕过大陆`).
4. Для всех программ: включи **TUN**.

### Телефон
- **iPhone:** Shadowrocket (платный, нужен не-китайский Apple ID), Stash, Hiddify, Streisand. Импорт по QR-коду из `vpn show`.
- **Android:** Hiddify, NekoBox, v2rayNG, Clash Meta for Android.

## Управление сервером

```
vpn show        — ссылки + QR-коды, пересоздать файлы клиента
vpn status      — состояние сервисов
vpn restart     — перезапуск
vpn logs        — логи
vpn update      — обновить Xray и Hysteria2 до последних версий
vpn sni <домен> — сменить сайт маскировки REALITY
vpn rotate      — новые ключи и пароли (если ссылки утекли)
vpn uninstall   — удалить всё
```

## Если перестало работать

| Симптом | Что делать |
|---|---|
| REALITY не подключается, Hysteria2 работает | Попробуй `vpn sni www.apple.com` (или другой сайт), затем переимпортируй ссылку/профиль. |
| Hysteria2 не работает, REALITY работает | Провайдер режет UDP/QUIC. Используй ссылку `MyVPN-HY2-HOP` (port hopping) или просто REALITY. |
| **Ничего не работает, сервер не пингуется из Китая, но доступен из других стран** | IP заблокирован GFW. Смени IP у хостинга (или пересоздай сервер), затем `NEW_IP=новый.ip vpn rotate`, либо просто снова запусти `install.sh` на новом сервере. |
| Медленно вечером | Плохой маршрут VPS. Переключись на HYSTERIA2. Кардинальное решение: VPS с CN2 GIA / CMI. |
| Китайские сайты/приложения тормозят или просят капчу | Проверь, что включена раздельная маршрутизация (в Clash это делается правилами из профиля, в Hiddify регион `cn`). |
| Проверка с сервера | `vpn status` и `vpn logs` |

**Советы, чтобы IP прожил дольше:**
- Не раздавай ссылки многим людям: большой трафик с одного IP привлекает внимание.
- Не ставь на этот же сервер сайты, панели (3x-ui и т.п.) и другие VPN-протоколы (OpenVPN/WireGuard/Shadowsocks GFW детектирует моментально).
- Во время крупных политических событий в Китае блокировки усиливаются. Держи резервный вариант (второй дешёвый VPS или коммерческий сервис).

## Безопасность

- Ключи хранятся на сервере в `/etc/myvpn/params.env` (доступ только root). **Не публикуй ссылки `vless://` и `hysteria2://`**: по ним кто угодно сможет пользоваться твоим сервером.
- Рекомендуется вход на сервер по SSH-ключу вместо пароля:
  ```bash
  # на ноутбуке
  ssh-keygen -t ed25519
  ssh-copy-id root@IP_СЕРВЕРА
  ```
- В Hysteria2 используется самоподписанный сертификат с привязкой отпечатка (`pinSHA256`) и обфускацией паролем, поэтому подменить сервер не получится.

## Структура

```
server/install.sh   — установка/переустановка (повторный запуск сохраняет ключи)
server/vpn          — утилита управления (ставится в /usr/local/bin/vpn)
```

На сервере после установки:
```
/usr/local/etc/xray/config.json   — конфиг Xray (REALITY)
/etc/hysteria/config.yaml         — конфиг Hysteria2
/etc/myvpn/params.env             — все ключи и пароли
/root/vpn-client/                 — links.txt, clash-mihomo.yaml, subscription.txt
```
